Imports with built-in backup

Everything starts with an import — a calendar from a file or a link. Calendar providers rarely offer backups and old events can vanish or be altered at the source. Here you keep your own history.

  • Uploaded files — import a static .ics file once.
  • Web calendars — subscribe by URL, refreshed automatically in the background.
  • Automatic backup — every changed version is stored, thinned out over time. Download any version or turn it into a new import.
  • Status at a glance — see when a calendar was last fetched and why a fetch failed.

Exports you can subscribe to

An export collects events from one or more imports, applies your rules and publishes the result as a regular calendar feed that works in any calendar app.

  • Combine several imports, each with its own filter and transform.
  • Memorable links — choose your own short, static link name.
  • Protected links — require a secret token and reroll it at any time to cut off access.
  • Always current — exports are rebuilt automatically when a source or a rule changes.

Shape events your way

Each source of an export has a filter that selects events and a transform that modifies the ones that are kept.

Filters are SQL

Write a plain WHERE clause against fields like summary, location, dtstart or status. Text matching, regular expressions, date ranges and durations are all supported. 

summary REGEXP '^(Training|Match)'
  AND status != 'CANCELLED'
  AND "all-day" = 0
  AND datetime(dtstart) >= datetime('2026-01-01')

Transforms are short commands

Chain commands to shift times, clip durations, overwrite or remove properties, trim overlaps and merge consecutive all-day events. 

shift:PT1H
clip-max-duration:PT2H
set-location:"Room 1"
remove:description
combine-all-day

Boards: one link for many calendars

A board is a public page that lists a selection of your exports with a name and description. People open it, choose the calendar that fits them and subscribe — no account needed.

  • Pick which exports appear on the board
  • Custom link name, optional token protection
  • Perfect for clubs, teams, classes and communities

Yours to run

Calendar Manager is open source. Your calendars and your data stay on your own server.

Up in minutes with Docker Compose

One compose file starts the app and its PostgreSQL database.

git clone https://github.com/lukasstorck/calendar-manager
cd calendar-manager

cp .env.example .env
# disable oidc auth for demo
sed -i 's/^SKIP_AUTHENTICATION=.*/SKIP_AUTHENTICATION=true/' .env

docker compose up --build

Sign in with your own identity provider

Authentication is delegated to OpenID Connect — no passwords are stored. Configure the providers you want to offer and users log in with them.
